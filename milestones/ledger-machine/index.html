Published Ledger on HackMyVM

Small accounting web target built and released for HackMyVM.

After building personal finance tools in the terminal, I wanted to design a vulnerable machine around an everyday office app instead of a contrived CTF puzzle. Ledger drops you in front of SimpleLedger, a stripped-down web portal used to upload accounting sheets and view reports.

I built and tested this VM on VirtualBox. If you want to play it blind, download the archive below, import the OVA on your lab network, and start with standard service enumeration. Everything needed to move from initial access to root lives inside the box with no guessing.

Download VM on MEGA
How was this machine built and solved? Contains spoilers

I built SimpleLedger as a small Python Werkzeug app on port 5000 alongside SSH on port 22. Inside the CSV upload handler, I deliberately wired the multipart filename straight into a shell command without sanitization so players spot the injection by watching how the upload behaves.

Rather than hiding credentials behind brute-force wordlists, I placed an encoded SSH password for the local finance user inside a process environment variable. For root, I compiled a minimal setuid C archiver that copies files without validating destination paths, giving that account a clean write path into sudoers.
