Published Grenade on HackMyVM

WordPress target hosted on AlmaLinux for HackMyVM.

Grenade was my attempt at building a box on AlmaLinux with SELinux active rather than using the usual Debian or Ubuntu defaults. On the surface it presents a straightforward charity donation site running WordPress.

Built and tested on VirtualBox, the VM lets players feel what happens when an initial shell lands inside a tightly confined web context instead of an unrestricted Linux host. Grab the OVA below if you want to try breaking out on your own first.

Download VM on MEGA
How was this machine built and solved? Contains spoilers

I set up Apache on port 8080 inside AlmaLinux with SELinux active, serving WordPress 6.6.2 and GiveWP 4.16.5.1. That plugin version is vulnerable to CVE-2026-82222, an unauthenticated PHP object injection flaw in the donation form flow that chains unsafe deserialization into remote code execution, landing as the web user trapped inside the HTTP domain.

To give players a way out of that sandbox, I stored an encoded credential backup on disk that opens a regular SSH session as a local user without HTTP confinement. From there, I paired the box with an AlmaLinux 10 Linux 6.12 kernel affected by Dirty Frag (CVE-2026-43284 in xfrm-ESP and CVE-2026-43500 in RxRPC), two page-cache write bugs that let an unprivileged user overwrite read-only memory pages and escalate to root.
