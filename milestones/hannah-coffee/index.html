Published Hannah Coffee on DockerLabs

Lightweight cafe web container built and shipped for DockerLabs.

Hannah Coffee was the first vulnerable target I built from scratch as a portable Docker container. I wanted a beginner-friendly box with classic service interaction rather than a single isolated web bug, wrapped inside a small coffee shop site.

You can download the container bundle below and spin it up locally before checking how the services connect inside.

Download container on DockerLabs
How was this machine built and solved? Contains spoilers

I assembled the Debian container with supervisord running Apache on port 80 and vsftpd on port 21 together so both services touch the same FTP log. While the main navigation parameter stays whitelisted, I left a sibling parameter unvalidated inside PHP's include function, letting players execute PHP injected through an FTP login username.

Once on the box as the web user, a sudo rule grants access to an ext4 debugger over a 64 MB disk image holding an encoded user password (alongside the debugger's shell escape). For root, I placed a copy of Python with the setuid capability enabled so the user account can raise its UID to zero.
